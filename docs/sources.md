## 参考重绘

`hero-*.webp`、`staff-*.webp`、`wanted-*.webp`、`voices.webp`、`turing.webp`、`logo.webp` 使用图像生成工具参考截图重绘。人物相貌、姿势、细部装备和 Logo 字形存在差异，后续有原始素材时可直接替换。

`reference-home.png` 是公开攻略中的小尺寸首页截图，仅通过 CSS 显示其中的签名区域。原图清晰度有限。

论坛部分头像使用抽象图标代替。装饰横幅的光带和页面动效由 CSS 实现，没有使用原始活动视频。
